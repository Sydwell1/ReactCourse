# Beginning React with Hooks: chapter 5 starting point (Vite)

The project as it stands at the end of chapter 4: a product listing (`Products.jsx`, `Product.jsx`, `Rating.jsx`). Chapter 5 of the book starts from here.

```
npm install
npm run dev
```

Open http://localhost:5173. Needs Node.js 20.19 or newer (or 22.12+). The product images load from picsum.photos, so they need an internet connection.

Follow the book's chapter 5. The book's `Jumbotron` no longer exists in react-bootstrap 2; the course page shows the replacement (`HeroCard`).
