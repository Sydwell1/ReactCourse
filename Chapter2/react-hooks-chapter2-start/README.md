# Beginning React with Hooks: chapter 2 starting point (Vite)

The project as it stands at the end of chapter 1: the Vite scaffold with `src/App.jsx` showing "Learn React Hooks". Chapter 2 of the book starts from here.

```
npm install
npm run dev
```

Open http://localhost:5173. Needs Node.js 20.19 or newer (or 22.12+).

Follow the book's chapter 2. Where the book names a file `Products.js`, create `src/Products.jsx`. The course page has a table of every difference.
