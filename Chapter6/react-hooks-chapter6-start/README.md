# Beginning React with Hooks: chapter 6 starting point (Vite)

The project as it stands at the end of chapter 5: the product list, `HeroCard`, and `props.children`. Chapter 6 of the book starts from here and adds a login form (`UserForm.jsx`).

```
npm install
npm run dev
```

Open http://localhost:5173. Needs Node.js 20.19 or newer (or 22.12+).
