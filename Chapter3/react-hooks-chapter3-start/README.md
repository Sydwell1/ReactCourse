# Beginning React with Hooks: chapter 3 starting point (Vite)

The project as it stands at the end of chapter 2: `Products.jsx` lists three products and `App.jsx` shows a greeting, an image and `<Products />`. Chapter 3 of the book starts from here.

```
npm install
npm run dev
```

Open http://localhost:5173. Needs Node.js 20.19 or newer (or 22.12+).

Follow the book's chapter 3. You will install react-bootstrap, bootstrap and react-icons yourself (the book gives the commands), and create `src/Rating.jsx` (the book says `Rating.js`). The course page has a table of every difference.
