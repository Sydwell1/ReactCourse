# Beginning React with Hooks: chapter 8 starting point (Vite)

A new Vite React project (JavaScript) for the ToDo app, with the packages the book installs at the start of chapter 8 already added: `axios`, `uuid`, `react-bootstrap` and `bootstrap`. The Bootstrap CSS is imported in `src/main.jsx` (the book's `index.js`).

```
npm install
npm run dev
```

Open http://localhost:5173. Needs Node.js 20.19 or newer (or 22.12+). Then follow the book's chapter 8 from "Avoiding Props Drilling with React Context".
