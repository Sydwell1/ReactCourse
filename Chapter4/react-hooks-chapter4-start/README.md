# Beginning React with Hooks: chapter 4 starting point (Vite)

The project as it stands at the end of chapter 3: react-bootstrap, bootstrap and react-icons are installed, `Rating.jsx` has its own state, and `App.jsx` shows the product list, a button and five ratings. Chapter 4 of the book starts from here.

```
npm install
npm run dev
```

Open http://localhost:5173. Needs Node.js 20.19 or newer (or 22.12+).

Follow the book's chapter 4. Where the book names a file `Product.js`, create `src/Product.jsx`. The course page lists what to change where the book's code no longer works (the `Media` component).
