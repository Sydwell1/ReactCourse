# Beginning React with Hooks: chapter 9 starting point (Vite)

The ToDo app as it stands at the end of chapter 8: add, edit and delete todos with `useReducer` and Context, with the data held only in the browser. Chapter 9 connects it to an API so the todos are saved.

```
npm install
npm run dev
```

Open http://localhost:5173. Needs Node.js 20.19 or newer (or 22.12+).
