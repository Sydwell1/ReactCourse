# Beginning React with Hooks: chapter 5, finished (Vite)

The project after chapter 5. `Products.jsx` shows the product list only when there are products, and "No Products to display" otherwise (conditional rendering with `&&`). `HeroCard.jsx` shows content passed from outside with `props.children`, or default text when none is given. `App.jsx` shows the products and two `HeroCard`s.

```
npm install
npm run dev
```

Open http://localhost:5173. Needs Node.js 20.19 or newer (or 22.12+). The product images load from picsum.photos, so they need an internet connection.
